# Project Notes for Agents

Use this file to record common mistakes, confusion points, and surprising
project behavior that future agents should know.

When you encounter one:

- Tell the developer what surprised you and why.
- Add or suggest a short note here so future agents avoid the same issue.
- Keep notes specific and reusable.

## Project context

- This is a personal project. Break substantial additions into manageable
steps so the developer can review and understand them without being
  overwhelmed by code or documentation.
- Removal, simplification, and replacement can be broad when that makes
  the result clearer.
- The project is still exploratory. Breaking changes and major rewrites
  are welcome when they serve the current goal; existing architecture
  and compatibility are not requirements by default.
